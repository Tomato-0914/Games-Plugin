# 飞行棋 设计报告

> 所属插件：Games-Plugin　分类：棋类（掷骰子）　游戏标识：`FlyingChess`
> 状态：已确认，v1.7.0 已实现（见第 8 节确认结果）

---

## 1. 规则速览

飞行棋各地玩法细节不同，下表是最常见的版本，也是本插件的默认规则（标 ⚙️ 的可以在配置里改）。

| 规则 | 说明 |
| --- | --- |
| 人数 | 2–4 人，红、黄、蓝、绿四色，每人 4 架飞机，开局都在自己的停机坪 |
| 棋盘 | 外圈一圈共 52 格，四种颜色依次循环；每种颜色还有一条通往中心的 6 格终点通道 |
| 起飞 | 掷出 **6 点** 才能让一架飞机从停机坪起飞到起飞点 ⚙️（可改为 5、6 点都能起飞） |
| 走棋 | 起飞后按点数前进；每人只走外圈 50 格，然后拐进自己颜色的终点通道 |
| 连掷 | 掷出 6 点可以再掷一次；**连续三次掷出 6**，本回合作废，轮到下一位 ⚙️ |
| 跳子 | 停在**自己颜色**的格子上，直接跳到前方下一个同色格（前进 4 格） |
| 飞棋 | 每种颜色有一条虚线捷径：停在自己颜色的飞行起点，沿虚线直接飞到对面（前进 12 格）；一次移动最多“跳一次 + 飞一次” |
| 撞子 | 停在对方飞机所在的格子，对方这一格的飞机全部被撞回停机坪 |
| 叠子 | 自己的飞机停在同一格就叠在一起，各自照常走；对方叠子**不挡路** ⚙️ |
| 终点 | 必须**正好**走到终点；点数多了就从终点**往回退**多出的步数 ⚙️ |
| 胜负 | 四架飞机最先全部到达终点的一方获胜；默认产生第一名就结束 ⚙️（可改为继续比出第 2、3 名） |

## 2. 一局的流程

```text
小明：#发起飞行棋            → 小明执红，等待其他人加入（5 分钟）
小红：#加入飞行棋            → 小红执黄
小刚：#加入飞行棋            → 小刚执蓝
小明：#开始飞行棋            → 人数够 2 人即可开始；也可以 #开始飞行棋 补机器人 把空位补成机器人
Bot ：[棋盘图] 轮到 @小明（红）掷骰子           [掷骰子]
小明：#掷骰子（或点按钮）
Bot ：🎲 6！选择要起飞 / 移动的飞机：1 2 3 4   [1号] [2号] [3号] [4号]
小明：1
Bot ：[棋盘图] 红 1 号起飞！掷出 6 可以再掷一次   [掷骰子]
...
```

- **只有一种走法时自动走**，不用再选；没有可走的飞机（比如没掷到 6、全在停机坪）就自动跳过。
- 选飞机：发 `1`–`4`，或点对应按钮；棋盘图上每架飞机都标了编号。

## 4. 计时与托管

4 个人一起玩，一个人不在就会卡住所有人，所以**超时不判负，改为自动走**：

- 每次操作（掷骰子、选飞机）限时 **60 秒**；超时由机器人代掷、代选。
- 同一个人连续 **3 次** 超时，自动转为机器人托管，本人发任意指令（如 `#掷骰子`）即可接回。
- 机器人的策略：能撞子先撞子 → 能进终点先进 → 能起飞先起飞 → 走最前面、最安全的一架。

## 5. 棋盘图片

- 方形棋盘，四角是红、黄、蓝、绿四个停机坪；外圈 52 格按四色循环；四条终点通道通向中心。
- 飞行捷径用同色虚线箭头画出。
- 飞机用对应颜色的圆形棋子表示，上面标编号 1–4；叠在一起时显示“×2”这样的数量。
- 顶部显示四位玩家（当前回合高亮）、各自已到终点的飞机数；底部显示上一次掷骰和走法，例如“红 掷出 4：2 号前进 4 格，跳子 +4，撞回黄 3 号”。

## 7. 需要你确认的问题

1. **起飞点数**：只有 6 点能起飞，还是 5、6 点都能起飞（节奏更快）？
2. **终点**：必须正好走到，多出来的往回退，可以吗？（另一种玩法是点数超过就不能走）
3. **叠子挡路**：对方叠在一起的飞机要不要挡路（不能越过，掷 6 才能越过）？默认不挡，规则简单些。
4. **连掷三个 6**：本回合作废可以吗？（更严的玩法是走得最远的一架飞机退回停机坪）
5. **超时**：每次操作 60 秒、超时代走、连续 3 次转托管，可以吗？
6. **机器人**：允许人不够时补机器人、也允许单人和机器人玩，可以吗？
7. **结束条件**：第一名产生后继续排完名次，还是第一名产生就结束？（默认第一名产生就结束，群聊里节奏更快）

## 8. 确认结果（按此实现）

| 问题 | 结论 |
| --- | --- |
| 起飞点数 | 只有 6 点 |
| 终点 | 必须正好走到，多出的往回退 |
| 叠子 / 撞子 | 停在对方飞机的格子就把对方（整格，含叠子）撞回停机坪；只有自己的飞机能叠在一起；对方叠子不挡路 |
| 连掷三个 6 | 本回合作废 |
| 超时 | 每次操作 60 秒，超时机器人代走；连续 3 次转托管，发任意飞行棋指令接回 |
| 机器人 | 人不够可以补机器人；也可以单人和 1–3 个机器人玩 |
| 结束 | 排出第 1、2、3 名，最后一名为输（2 人局第 2 名为输） |

**实现细节**

- 棋盘为 15×15 十字形：外圈 52 格四色循环，各色走 50 格后进 5 格终点通道，第 6 步到中心。
- 自己颜色的格子每 4 格一个，跳子 +4；飞行捷径在第 5 格，飞到第 17 格（12 格），横穿下一位玩家终点通道的最后一格，那里的对方飞机同样被撞回。
- 一次移动最多“跳一次 + 飞一次”：落在同色格先跳，跳到捷径起点再飞；直接落在捷径起点先飞，飞完再跳一次。
- 两人局坐对角（红、蓝），三人局红黄蓝。
- 同一格的多架飞机走法相同，只算一种走法；只有一种走法时自动走。
- 机器人连续行动时，一条消息里只显示最近 8 步，超时、托管等提示总是完整显示。
