## 功能

### 中国象棋

- 群内双人对战：一人发起、一人加入，加入后立即开局；红黑可以指定，也可以随机
- 人机对战：群聊、私聊都可以，四档难度（入门 / 简单 / 普通 / 困难），AI 在独立线程中思考，不卡 Bot
- 完整规则：蹩马腿、塞象眼、炮架、将帅照面、困毙判负、长将判负、自然限着
- 中文记谱（`炮二平五`、`马8进7`、`前车进一`）和坐标（`h2e2`）两种走法，走错会说明原因
- 棋盘图片：跟随行棋方翻转（轮到哪一方，哪一方在下），标出上一步和将军，四周印纵线编号和坐标；没有浏览器时自动改发文字棋盘
- 每步限时（默认 120 秒），超时前提醒，超时判负
- 悔棋、求和、认输；重启后对局自动恢复
- 适配 LLOneBot（OneBot v11）和 QQ 官方机器人（[QQBot-Plugin](https://github.com/Tomato-0914/QQBot-Plugin)），官方机器人下附带按钮

### 五子棋

- 15×15 白色棋盘，四周印列字母 A–O 和行号 1–15；黑先，五子连珠为胜
- 黑方禁手：三三、四四（同时成五时不算）；黑方回合在棋盘上用 × 标出禁手点
- 群内双人对战、人机对战（简单 / 普通 / 困难），AI 执黑时同样遵守禁手
- 悔棋、求和、认输（双人需对方同意）；每步限时；重启后恢复

### 扫雷

- 初级 9×9 / 中级 16×16 / 高级 16×30，也可以自定义大小和雷数
- 第一下必定安全；**无猜模式**：只生成靠推理就能扫完的棋盘
- 坐标直接发：`C5` 翻开，`旗C5` 插旗，`c1c2c3` 一次多格；对已翻开的数字再发一次坐标即快速翻开
- 提示（每盘次数可配置）；自动翻开固定开启：数字周围插的旗数等于数字时自动翻开其余格子
- 一个群同时一盘，私聊每人一盘；10 分钟无操作提醒后判定失败；重启后恢复

### 通用

- `#游戏帮助` 列出所有游戏，帮助均为图片
- `#游戏更新` 一键更新并自动重启

## 安装

在 Yunzai 根目录执行：

```sh
git clone --depth 1 https://github.com/Tomato-0914/Games-Plugin ./plugins/Games-Plugin
```

插件没有额外依赖，不需要 `pnpm install`。重启 Bot 即可使用。

棋盘图片使用 Yunzai 自带的 puppeteer 渲染，与其他插件的帮助图片相同。插件内置了霞鹜文楷字体（`resources/fonts/`），服务器不需要另外安装中文字体。

## 从 Chess-Plugin 升级

仓库已从 `Chess-Plugin` 改名为 `Games-Plugin`，旧地址会自动跳转，已安装的插件发 `#游戏更新`（或旧指令 `#棋更新`）照常更新。

- 插件文件夹可以继续叫 `plugins/Chess-Plugin`，不影响使用
- 建议把远程地址改成新的：在插件目录执行 `git remote set-url origin https://github.com/Tomato-0914/Games-Plugin`
- 进行中的对局、配置文件都不受影响

## 指令

`#游戏帮助` 列出插件里所有游戏；每个游戏的玩法用各自的帮助指令查看，例如 `#象棋帮助`。

### 中国象棋

| 指令 | 说明 |
| --- | --- |
| `#象棋` / `#象棋帮助` | 象棋玩法与指令（图片） |
| `#发起象棋` / `#发起象棋 红` / `#发起象棋 黑` | 发起双人对局（群聊）；不指定颜色时，开局随机分配红黑 |
| `#加入象棋` | 加入对局，加入后立即开始，红方先走 |
| `#人机象棋 [难度] [红/黑]` | 人机对战，默认执红先走；官方机器人下不写难度时先发难度按钮选择，其他适配器默认“普通” |
| `炮二平五` / `马8进7` / `h2e2` | 轮到你时直接发送走法 |
| `#棋盘` | 重新发送棋盘 |
| `#悔棋` | 双人：需对方 `#同意悔棋`；人机：每局 3 次 |
| `#求和` | 双人：需对方 `#同意求和`；人机：由 AI 根据局面决定 |
| `#认输` | 双人：需对方 `#同意认输`（`#拒绝认输` 则继续对局）；人机：直接认输 |
| `#结束象棋` / `#取消象棋` | 强制结束，不计胜负（发起人取消等待中的对局；对局中需群管理或主人；人机对局玩家本人可结束） |

英文指令：`#Chinese_Chess create | join | ai | board | undo | draw | resign | end | help`，
人机难度也可以写 `beginner / easy / normal / hard`，颜色写 `red / black`。

### 象棋走法写法

- 中文纵线记谱：`棋子 + 起始纵线 + 进/退/平 + 目标`，例如 `炮二平五`、`马8进7`、`车一进一`
- 同一纵线有两个同类棋子：`前车进一`、`后马退二`；三个兵：`前兵`、`中兵`、`后兵`
- 红方习惯用中文数字、黑方习惯用阿拉伯数字，两种数字双方都能识别；繁体（`傌`、`俥`、`砲`）也能识别
- 坐标：`h2e2`（列 a–i，行 0–9，红方在下），棋盘图四周印有坐标

### 五子棋

| 指令 | 说明 |
| --- | --- |
| `#五子棋` / `#五子棋帮助` | 五子棋玩法与指令（图片） |

| `#加入五子棋` | 加入对局，加入后立即开始，黑方先下 |

| `H8` / `8H` / `下H8` | 轮到你时直接发送坐标（列字母 A–O + 行号 1–15）；官方机器人下有“落子”输入按钮 |

英文指令：`#Gomoku create | join | ai | board | undo | draw | resign | end | help`。

同一个群里可以同时有一局象棋、一局五子棋和一盘扫雷；`#悔棋`、`#认输` 这类通用指令按你参与的那一局处理。

## 配置

`config/config.yaml`，首次启动时从 `config/default_config/config.yaml` 复制，保存后自动生效：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `xiangqi.joinTimeout` | `300` | 等待对手加入的时间（秒） |
| `xiangqi.moveTimeout` | `120` | 每步思考时间（秒），超时判负 |
| `xiangqi.moveWarnBefore` | `30` | 超时前多少秒提醒，0 不提醒 |
| `xiangqi.naturalLimit` | `60` | 双方连续多少回合没有吃子判和，0 不限制 |
| `xiangqi.boardFollowTurn` | `true` | 棋盘跟随行棋方：轮到哪一方，哪一方在下；`false` 为红方始终在下 |
| `xiangqi.defaultAiLevel` | `普通` | 默认人机难度 |
| `xiangqi.aiUndoLimit` | `3` | 人机对战每局悔棋次数 |
| `xiangqi.requestTimeout` | `60` | 悔棋、求和请求的有效时间（秒） |
| `xiangqi.allowPrivate` | `true` | 是否允许私聊人机对战 |
| `gomoku.joinTimeout` / `moveTimeout` / `moveWarnBefore` / `requestTimeout` | `300` / `120` / `30` / `60` | 同象棋 |
| `gomoku.defaultAiLevel` | `普通` | 默认人机难度：简单 / 普通 / 困难 |
| `gomoku.aiUndoLimit` | `3` | 人机对战每局悔棋次数 |
| `gomoku.forbidden` | `true` | 黑方三三、四四禁手 |
| `gomoku.overline` | `win` | 长连（六子以上）：`win` 算赢，`forbidden` 黑方禁手 |
| `gomoku.forbiddenLoses` | `false` | 黑方下在禁手点：`false` 不允许落子并提示，`true` 直接判负 |
| `gomoku.showForbidden` | `true` | 黑方回合在棋盘上标出禁手点 |
| `minesweeper.defaultLevel` | `初级` | 不写难度时的默认难度（官方机器人下先发按钮） |
| `minesweeper.noGuess` | `true` | 无猜模式 |
| `minesweeper.idleTimeout` | `600` | 多少秒无操作判定失败，0 不限 |
| `minesweeper.idleWarnBefore` | `120` | 判定失败前多少秒提醒，0 不提醒 |
| `minesweeper.hintLimit` | `1` | 每盘提示次数，0 关闭提示 |
| `minesweeper.hintPenalty` | `10` | 每次提示计时增加的秒数 |
| `minesweeper.maxBatch` | `30` | 一条消息最多操作的格子数 |
| `minesweeper.maxRows` / `maxCols` / `maxDensity` | `20` / `30` / `0.3` | 自定义难度上限（行最多 26） |
| `engine.maxConcurrent` | `2` | 同时进行的 AI 思考数量 |
| `qqbot.buttons` | `true` | 官方机器人下是否附带按钮 |
| `render.textFallback` | `true` | 截图失败时改发文字棋盘 |

## 说明

- 双人对战中，每条群消息只有在**本群有进行中的对局、发送者是轮到的一方、内容就是一步棋**时才会被当作走子，平时聊天不受影响
- QQ 官方机器人开启“接收群内全部消息”后，走子不需要 @机器人；未开启时需要 @机器人 才能收到消息
- 同一个群里同时有官方机器人和 LLOneBot 时，对局只由开局的那个 Bot 处理，不会重复回复
- 重复局面：一方一直将军（长将）判负，其他情况三次重复判和；“长捉”暂未判定
- AI 是插件内置的搜索引擎（纯 JavaScript），不需要安装其他程序
- 五子棋的禁手按连珠规则判定：活三指能形成活四、且形成活四的那一手本身不是禁手的三；同一条线上的两个四（如 `●·●●●·●`）也算四四
- 五子棋 AI 是内置的五元组评估 + Alpha-Beta 搜索，困难难度单步通常不到 1 秒
- 扫雷的坐标也只在**你自己有一盘进行中、整条消息就是坐标**时才处理；同一个人同时下象棋时，`h2e2` 这种四位坐标优先当作象棋走法
- 官方机器人的被动回复只在用户发消息后 5 分钟内有效：扫雷 10 分钟闲置的提醒和判负消息会改用主动消息发送，受官方主动消息额度限制，可能发不出去（判定照常生效）

## 开发

```sh
pnpm test   # 或 npm test
```

测试覆盖：象棋走法生成（perft）、特殊规则、记谱解析、AI；五子棋禁手（三三、四四、同线四四、被堵的三、五连优先、长连）、AI；扫雷规则、求解器正确性、无猜生成；以及模拟 Yunzai 环境下的完整对局流程。

每个游戏的规则在 `games/<游戏>/`，不依赖 Yunzai；`apps/` 负责指令和消息；`components/` 是共用的房间、截图、帮助图、AI 调度、配置和适配器工具。新增游戏时在 `components/Games.js` 登记，`#游戏帮助` 会自动列出。
